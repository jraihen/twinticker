# 트윈티커 초기 구상

작성일: 2026-08-23  
상태: 아이디어 단계 / MVP 정의 전

## 1. 한 줄 정의

트윈티커는 두 개의 금융 자산을 같은 시간축 위에 올려놓고, “무엇이 더 강했는가, 지금 무엇이 달라졌는가”를 빠르게 확인하게 해주는 비교형 티커다.

## 2. 문제

가격 앱은 개별 자산을 보는 데는 좋지만, 두 자산의 상대 성과를 비교하려면 화면을 오가거나 직접 계산해야 한다. 특히 다음 질문에 즉시 답하기 어렵다.

- 오늘/이번 주/올해 어느 쪽이 더 올랐는가?
- 가격이 아니라 수익률 기준으로 보면 결과가 같은가?
- 두 자산의 움직임은 함께 가는가, 갈라지고 있는가?
- 내가 정한 조건이 발생했는가?

## 3. 대상 사용자

1차 대상은 투자 초보부터 중급자까지의 개인 사용자다.

- ETF와 지수를 비교하는 사람
- 개별 종목과 벤치마크를 비교하는 사람
- 주식·코인·환율 등 두 자산의 상대 움직임을 관찰하는 사람
- 복잡한 트레이딩 기능보다 빠른 상황 파악을 원하는 사람

## 4. 핵심 경험

사용자는 자산 A와 B를 선택하고, 기간을 고른다. 트윈티커는 두 자산을 동일한 기준으로 정규화해 보여주고, 현재 격차와 주요 변화만 요약한다.

### 핵심 화면

- 상단: A/B 검색 및 교체, 기간 선택
- 중앙: 정규화 수익률 비교 차트
- 하단: 현재가, 기간 수익률, 변동성, 최고·최저, 격차
- 보조 영역: 가격 알림과 최근 이벤트

## 5. MVP 범위

### 반드시 포함

- 자산 검색 및 두 자산 고정
- 주식/ETF 등 한 종류의 데이터부터 지원
- 1일·1주·1개월·1년 기간 선택
- 정규화 비교 차트(시작값 100)
- 현재가, 등락률, 두 자산 간 성과 격차
- 모바일 우선 반응형 화면
- 마지막 선택 자산 로컬 저장

### 후순위

- 가격/수익률 조건 알림
- 여러 쌍의 워치리스트
- 상관계수와 변동성 비교
- 배당·분할 반영
- 코인, 환율, 원자재 등 데이터 소스 확장
- 로그인 및 클라우드 동기화

### MVP에서 제외

- 주문·매매 실행
- 투자 추천 또는 매수/매도 신호
- 자동 포트폴리오 관리
- 유료 데이터의 무단 재배포

## 6. 제품 원칙

- 비교는 한눈에: 두 자산은 항상 같은 축과 같은 기간으로 본다.
- 숫자는 설명 가능하게: 수익률 기준, 데이터 시각, 통화를 명확히 표시한다.
- 빠르게: 첫 화면은 차트가 보이기까지의 시간을 최소화한다.
- 절제된 금융 UI: 초록/빨강만으로 과도한 행동을 유도하지 않는다.
- 판단과 정보의 분리: 데이터는 제공하되 투자 조언처럼 표현하지 않는다.

## 7. 초기 기술 구상

초기에는 작은 웹 앱으로 시작한다.

- 프론트엔드: TypeScript 기반의 반응형 웹 UI
- 데이터 계층: 외부 시세 API를 감싸는 단일 어댑터
- 차트: 정규화 시계열과 툴팁을 지원하는 경량 차트 라이브러리
- 저장: MVP는 브라우저 로컬 저장소
- 구조: `ui → domain metrics → market data adapter`로 분리

데이터 제공업체는 가격·호출 제한·상업적 이용 조건을 비교한 뒤 확정한다. 공급업체 종속을 피하기 위해 화면 코드에서 API 응답 형식을 직접 다루지 않는다.

## 8. 기본 데이터 모델

```text
Asset
  symbol: string
  name: string
  market: string
  currency: string

QuotePoint
  timestamp: datetime
  close: number

Comparison
  assetA: Asset
  assetB: Asset
  range: 1d | 1w | 1m | 1y
  seriesA: QuotePoint[]
  seriesB: QuotePoint[]
  normalizedReturnA: number
  normalizedReturnB: number
  spread: number
```

## 9. 성공 기준

- 사용자가 10초 안에 비교할 두 자산과 기간을 선택할 수 있다.
- 차트와 요약 수치가 동일한 데이터 기준을 사용한다.
- 두 자산의 기간 수익률과 격차가 수동 계산으로 검증된다.
- API 실패, 데이터 지연, 시장 휴장 상태를 숨기지 않고 표시한다.
- 모바일 화면에서 핵심 비교 정보가 가로 스크롤 없이 보인다.

## 10. 첫 구현 순서

1. 앱 셸과 비교 화면의 정적 UI
2. 로컬 목업 시계열로 정규화 차트 구현
3. 비교 지표 계산 함수와 단위 테스트
4. 시세 API 어댑터 연결
5. 로딩·빈 상태·오류·지연 데이터 처리
6. 모바일 레이아웃과 접근성 점검

## 11. 아직 결정할 것

- 트윈티커의 주력 자산군: 미국 주식/ETF부터 시작할지, 국내 시장부터 시작할지
- 실시간 시세가 MVP에 필요한지, 지연 시세로 시작할지
- 로그인 없이 공개할지, 사용자별 워치리스트를 위해 계정을 도입할지
- 브랜드 톤: 분석 도구형인지, 가볍고 빠른 관찰 도구형인지
- 첫 데이터 API와 배포 환경

## 12. 추천 첫 스프린트 산출물

“두 자산을 선택하면 목업 데이터로 비교 차트와 4개 지표가 보이는 단일 화면”을 완성한다. 이 결과만으로도 제품의 핵심 가치가 전달되는지 검증할 수 있다.
